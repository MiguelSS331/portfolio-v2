# portfolio-v2

Local rebuild of Miguel Solano’s geospatial portfolio — Mapbox scrollytelling, separate from Portfolio-Miguel-Solano.

## Setup

```bash
cp .env.example .env.local
# add your Mapbox token + style URL
npm install
npm run dev
```

## Current slice

- Sticky Mapbox map (custom style)
- 2018: Mexico City point
- 2019: Mexico + Central America (El Salvador, Guatemala)
- Red year timeline on the map edge
